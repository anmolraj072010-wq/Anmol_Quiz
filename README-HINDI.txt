ANMOL QUIZ - APK BUILDER

Yeh APK banane ke liye Android project hai. Is ZIP mein game ka index.html pehle se app ke andar rakha gaya hai.

PHONE SE APK BANANE KE STEPS:
1. ZIP extract karo.
2. GitHub par sign in karke New repository banao: Anmol-Quiz (repository public ya private rakh sakte ho).
3. Is folder ke andar ki saari files/folders repository ke main branch mein upload karo. .github folder bhi zaroor upload karna.
4. Repository mein Actions tab kholo.
5. 'Build Anmol Quiz APK' workflow select karo.
6. 'Run workflow' dabao aur build complete hone do.
7. Workflow run ke neeche Artifacts mein 'Anmol-Quiz-debug-apk' download karo.
8. ZIP extract karke app-debug.apk par tap karke install karo. Android mein browser/files app ko install permission deni pad sakti hai.

NOTE:
- Yeh debug/test APK hai, Play Store release ke liye signed release build alag banana hoga.
- Online admin/leaderboard/daily quiz tabhi kaam karenge jab Supabase URL, anon key, database tables aur secure admin auth sahi configure hon.
- GitHub account banane/istemal karne ke liye platform ki age rules follow karo; agar zaroorat ho to parent/guardian ki madad lo. Kisi ko password ya private keys share mat karna.
